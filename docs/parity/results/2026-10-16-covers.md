# CapCut's draft covers as a parity check — 2026-10-16

Every CapCut draft folder holds `draft_cover.jpg`: CapCut's own render of the draft's first frame, at the canvas size, with animations applied. `openrip-dev cover-parity <projects-root>` renders the same frame with OpenRip and compares the two, across every local draft whose first-frame media is still on disk. It needs no export from CapCut, so it can be re-run after every change. Drafts are numbered, not named.

18 drafts compare (36 have media missing at the first frame).

Two findings came out of this check:
- **Line wrapping.** It was missing. The covers measured the rule; see [text-wrap.md](../text-wrap.md).
- **HLG phone video.** CapCut tone-maps it to SDR; see [hdr.md](../hdr.md).
